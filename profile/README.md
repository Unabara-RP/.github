# Unabara
We are a team of French computer science students working on a project to create a roleplay server based on the One Piece universe. We are currently using the game [Nanos World](https://nanos-world.com/) as our development framework.
Our **repositories** are **not** currently **available** to the public.

We are looking for talented individuals skilled in the following fields:
-   Unreal Engine 5
-   Lua
-   Blender
-   Game Design
-   Graphic Design
